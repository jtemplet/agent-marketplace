# Agent Marketplace

Personal Claude Code marketplace providing access to personal skills and custom agent skills.

## Installation

Register the marketplace:

```bash
/plugin marketplace add jtemplet/agent-marketplace
```

Install plugins:

```bash
# Custom agent skills
/plugin install templeton-agentic-dev-workbench@agent-marketplace
```

## Plugins

### templeton-agentic-dev-workbench

Custom skills for personal use. See [jtemplet/templeton-agentic-dev-workbench](https://github.com/jtemplet/templeton-agentic-dev-workbench).

### superpowers

Custom skills for personal use. See [jtemplet/superpowers](https://github.com/jtemplet/superpowers).

## Updating

Update plugins:

```bash
/plugin update templeton-agentic-dev-workbench
```
